# Hotel Chain Database Management System

An academic database project developed using **Oracle SQL and PL/SQL** to model and manage the operations of a hotel chain, including hotels, rooms, customers, reservations and billing.

## Project Objective

The objective of this project was to design and implement a relational database capable of supporting core hotel operations, with a focus on reservation management, room availability and financial information.

## Technologies

- Oracle SQL
- PL/SQL
- Oracle SQL Developer
- Relational Database Design

## Database Structure

The database is built around five main entities:

- **Hotels**
- **Rooms**
- **Customers**
- **Reservations**
- **Invoices**

The tables are connected through primary and foreign keys to maintain data integrity and represent the relationships between hotel operations.

## Key Features

The project includes:

- Relational database design using **primary and foreign keys**
- Table creation and data manipulation
- SQL queries using **joins and aggregations**
- PL/SQL control structures
- Explicit and implicit cursors
- Exception handling
- Stored procedures
- User-defined functions
- Reservation and billing calculations
- Hotel-level financial reporting
